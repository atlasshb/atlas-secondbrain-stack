# Sanitization report

This documents every real -> placeholder replacement and every file dropped
while assembling this public repo from the private source trees
`atlas-secondbrain/` and `cerebras/`. Line numbers refer to the **final**
(sanitized) files in this repo.

**Note on this report:** since this file itself ships in the public repo, it
describes each real value that was found and replaced rather than quoting the
literal value verbatim (no real IP, domain, or secret appears anywhere below,
including here) — that keeps the audit trail useful without re-publishing the
thing it's reporting on.

## 2. Critical finding: a real credential literal in a "scrub pattern"

**`secondbrain/brain.py`** (the credential-scrubbing regex table) contained a
regex entry whose pattern was not a generic shape but a **literal legacy
password string** being matched so it could be redacted from ingested text.
Because that literal string is itself a real secret, its presence in source
was a leak regardless of the entry's redaction *purpose*. The entry was
removed outright (was around line 66 of the original file); the neighboring
"known org-style password" regex was also generalized so no organization
name is embedded in the pattern. This was the single highest-severity finding
in the sanitization pass.

## 7. Env files — emptied per hard rule

`cerebras/env.d/cerebras.env.example` previously shipped a **non-empty**
`ODOO_URL=` default pointing at a real internal IP. All values in that file,
and in the new root `.env.example`, now ship empty (`VAR=`) with explanatory
comments only — no real defaults, no real secrets.

## 8. New scaffolding added (not sanitization, but part of the assembly)

- `secondbrain/Dockerfile` + `secondbrain/requirements.txt` — the source tree
  had no container build for the Second Brain (it ran natively via a host

- Root `docker-compose.yml`, `.env.example`, `.gitignore`, `LICENSE` — new
  files per the release brief, all placeholders / no real values.
